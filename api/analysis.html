Analysis

The analysis package evaluates the radiometry and ray-tracing data and contains the analyses behind the numbers and tables of the publication. Reproducing the Publication lists which function produces which figure, table or number.

Raytracing Data Processing

analysis.process_raytracing_data.calc_metrics(irr: pandas.Series)[source]

Compute the mean irradiance and homogeneity index from a series of irradiance values.

The homogeneity index is defined as \(1 - \frac{\sigma}{\mu}\) where \(\sigma\) is the standard deviation and \(\mu\) is the mean of the irradiance values. This provides a measure of uniformity, with 1 indicating perfect homogeneity.

Parameters:

irr (pandas.Series or numpy.ndarray) – Irradiance values to analyze.

Returns:

Tuple containing:

  • mean_irradiance (float): Mean of the irradiance values (W m⁻²).

  • homogeneity (float): Homogeneity index (dimensionless, 0 to 1).

Return type:

tuple

Raises:

ValueError – If the input series is empty.

Note

  • If the mean irradiance is zero, the homogeneity index is set to 0 to avoid division by zero.

analysis.process_raytracing_data.process_raytracing_file(filename: str, path: str) → pandas.DataFrame[source]

Parse a Speos raytracing output text file and return a DataFrame containing spatial coordinates and irradiance values.

This function reads a whitespace-delimited text file generated by Speos raytracing simulations, extracts the spatial coordinates (x, y, z in mm), and the irradiance (in W m⁻²), converts coordinates to centimeters, and returns a DataFrame with a uniform grid suitable for further analysis or visualization. Only the columns corresponding to the two varying spatial dimensions and the irradiance are retained in the output.

Parameters:

  • filename (str) – Name of the Speos output text file to read.

  • path (str or pathlib.Path) – Path to the directory containing the text file.

Returns:

DataFrame with columns [“x”, “y”, “Irradiance”], where x and y are in centimeters and Irradiance is in W m⁻².

Return type:

pandas.DataFrame

Raises:

  • FileNotFoundError – If the specified file does not exist.

  • ValueError – If the file format is not as expected or columns are missing.

Note

  • Assumes the input file has a header row and columns in the order: x, y, z, Irradiance, Reflection (Radiometric), Transmission (Radiometric), Absorption (Radiometric).

  • Only two spatial dimensions are retained (the two that vary in the dataset).

  • Coordinates are converted from millimeters to centimeters.

Example Usage

# Load raytracing data
df = process_raytracing_file('best_manual_no_reflector.txt', 'results/raytracing/LST1-01G01-UV01-00/')

# Calculate metrics
mean_irr, homogeneity = calc_metrics(df['Irradiance'])
print(f'Mean Irradiance: {mean_irr:.2f} W/m²')
print(f'Homogeneity Index: {homogeneity:.4f}')

# Create visualization
fig, ax = plt.subplots(figsize=(8, 6))
plot_irradiance_raytracing(ax, df, title='Irradiance Distribution')
plt.show()

analysis.process_radiometry_data.calculate_correction_factor(reference_filepath: str, expected_value: float) → float[source]

Computes a correction factor for radiometry data using a reference measurement and an expected radiant flux.

The function integrates the measured irradiance over the scanned area (using the pixel size inferred from the DataFrame’s index/columns), compares the result with the expected value, and returns the scaling factor that makes the integral of the reference scan equal to the expected radiant flux.

Parameters:

  • reference_filepath (str) – Path to the reference CSV file containing measured irradiance data.

  • expected_value (float) – Expected radiant flux on the scanned area in W, e.g. the number of LEDs times the optical power per LED from the datasheet.

Returns:

Correction factor to apply to radiometry data (float).

Return type:

float

Raises:

  • FileNotFoundError – If the reference file does not exist.

  • pd.errors.ParserError – If the file cannot be parsed.

  • IndexError – If the DataFrame does not contain enough data to infer pixel size.

Side effects:

None.

Note

  • The units of the original data (e.g., umol m⁻² s⁻¹ or W m⁻²) do not affect the correction factor calculation.

  • Assumes uniform pixel size and that index/columns are in centimeters.

  • Scaling the reference scan to the emitted flux assumes that the entire emitted flux reaches the scanned area. The share that actually reaches it, and its effect on the radiometric mean irradiance, are estimated in analysis.uncertainty.radiometry_corrections() (Supporting Information Section S10).

Loads radiometry data from a CSV file and returns it as a pandas DataFrame.

The function attempts to read the file using two different decimal and separator conventions to accommodate variations in CSV formatting. The first attempt assumes European-style CSVs (comma decimal, semicolon separator). If the resulting DataFrame is empty, it retries with standard CSV formatting (dot decimal, comma separator). Column and index names are converted to floats for consistency.

Parameters:

filepath (str) – Path to the CSV file containing radiometry data.

Returns:

DataFrame containing irradiance data, with both index and columns as floats representing spatial positions (typically in cm).

Return type:

pandas.DataFrame

Raises:

  • FileNotFoundError – If the file does not exist at the given path.

  • pd.errors.ParserError – If the file cannot be parsed as a CSV.

Side effects:

None.

Note

  • Assumes the first row and column of the CSV are headers and indices, respectively.

  • Handles both European and standard CSV formats.

  • All positions are assumed to be in centimeters unless otherwise specified.

Example Usage

Radiometry Data Processing: Indirect Irradiation Module

analysis.process_radiometry_indirect.process_radiometry_data(filepath: str, height: float = 0.33, width: float = 0.34) → tuple[pandas.DataFrame, float, float][source]

Processes radiometry data for indirect irradiation experiments, following the methodology described in Kowalczyk et al. (2023), DOI: 10.1039/D3RE00398A. This function reads radiometry data from a CSV file, determines the mean irradiance based on published received optical power for specific LED types, and calculates the homogeneity of the irradiance distribution. The function is tailored for datasets with a specific format and LED types as described in the referenced publication.

The CSV file is expected to contain columns for x, y, and z coordinates (with z representing measured irradiance values), separated by semicolons and without a header row. The function automatically crops the data to a region of interest based on published values and applies a correction factor for certain LED types.

Parameters:

  • filepath (str) – Path to the CSV file containing radiometry data. The file must use semicolon (‘;’) as a delimiter and contain columns for x, y, and z (irradiance) values. The LED type must be identifiable from the filepath string (see Notes).

  • height (float, optional) – Height of the detection plane in meters. Default is 0.33 m.

  • width (float, optional) – Width of the detection plane in meters. Default is 0.34 m.

Returns:

A tuple containing: - irr (pandas.DataFrame): Cropped irradiance data with columns [‘x’, ‘y’, ‘z’]. - mean_irradiance (float): Mean irradiance in W/m², calculated from published optical power and detection plane area. - homogeneity (float): Homogeneity of the irradiance distribution, defined as 1 - (standard deviation / mean) of the irradiance values.

Return type:

tuple[pandas.DataFrame, float, float]

Raises:

ValueError – If the LED type cannot be determined from the filepath.

Note

  • Only supports LED types “LST1-01G01-UV01-00” and “LST1-01F06-GRN1-00” as identified in the filepath. For the green LED, a correction factor is applied to estimate optical power at 350 mA from 1 A data.

  • The region of interest is cropped to x in [11, 45] and y in [16, 49] as per the referenced publication.

  • The CSV file must not contain a header row; the first row is skipped.

  • The returned irr DataFrame has columns ['x', 'y', 'z'] (where z is the irradiance). To visualize it, use analysis.process_raytracing_data.plot_irradiance_raytracing() after renaming the z column to Irradiance.

Side effects:

None. The function only reads from the specified file and returns processed data.

References:

Kowalczyk et al., Reaction Chemistry & Engineering, 2023, DOI: 10.1039/D3RE00398A

Example Usage

# calculate mean irradiance and homogeneity index from an indirect irradiation measurement
irr, mean_irradiance, homogeneity = process_radiometry_data('results/radiometry/LST1-01G01-UV01-00/indirect_irradiation.csv')
print(f'Mean Irradiance: {mean_irradiance:.2f} W/m²')
print(f'Homogeneity Index: {homogeneity:.4f}')

# Visualize the irradiance distribution using the raytracing plot helper
# (irr is a DataFrame with columns ['x', 'y', 'z'])
from analysis.process_raytracing_data import plot_irradiance_raytracing
from matplotlib import pyplot as plt

fig, ax = plt.subplots(figsize=(8, 6))
plot_irradiance_raytracing(ax, irr.rename(columns={'z': 'Irradiance'}), title='Indirect Irradiation - Irradiance Distribution')
plt.show()

Fast Evaluation of Many Configurations

Fast and exact evaluation of many LED configurations with the geometric model.

The Monte-Carlo studies of the Supporting Information (Sections S11 and S12) evaluate up to 10 million configurations per random seed. Simulating each configuration with geometric_model.GeometricModel.simulate() would take days, so this module uses the linearity of the model instead.

For a fixed height z the irradiance field of a configuration is the superposition of the fields of its LEDs (Eq. (10) of the manuscript), E = m^T F_z, where m is the 0/1 indicator vector over the 169 mounting positions and F_z (169 x number of grid points) holds the single-LED fields computed with GeometricModel.simulate(). Hence

  • E_mean = m^T mu_z with mu_z the mean of every single-LED field,

  • sum(E^2) = m^T G_z m with the Gram matrix G_z = F_z F_z^T,

  • std(E) = sqrt(sum(E^2) / n - E_mean^2) (population standard deviation, as numpy.std()),

  • max(E) needs the field itself; it is evaluated by a matrix product on one half of the grid. This is exact because every sampled configuration is point-symmetric about the module centre and the evaluation grid is symmetric about it with an even number of rows (both are checked).

tests/test_fast_evaluation.py checks that the result equals the stored results of the systematic 8-LED study (relative deviations below 1e-6; the maximum is evaluated in single precision).

The module also holds the selection procedure of the manuscript on precomputed metrics (select_configurations()) and the non-dominated filter used for the Pareto fronts.

Point-Source Assumption

Sensitivity of the geometric model to the point-source assumption (Supporting Information S9).

The geometric model treats every LED as a point source (Eq. (9) of the manuscript). Here every LED is replaced by a uniformly emitting planar disk of diameter d whose surface elements all radiate with the radiant-intensity profile of Eq. (6), weighted by their share of the disk area. The contribution of an LED is therefore the point-source contribution averaged over the disk (Eq. (S10) of the Supporting Information):

E_i,disk(x, y) = 4 / (pi d^2) * int_0^{2 pi} int_0^{d/2} E_i(x - rho cos phi, y - rho sin phi) rho drho dphi

It is evaluated with 12 Gauss-Legendre nodes in (2 rho / d)^2 (area-uniform) and 24 equidistant nodes in phi. d is the lens diameter given in the datasheets: 2.6 mm for the 365 nm LED (Luminus SST-10-UV, lens radius R1.30) and 2.15 mm for the 530 nm LED (OSRAM GT CSSPM1.13).

Evaluated are all investigated configurations at their heights (best manual configuration for both LED types, UV1-UV3, GRN1-GRN3) and UV3 and GRN3 at 5 cm, the smallest height of the optimization. The result is Table S3 of the Supporting Information.

Monte-Carlo Samples of the Convergence Study

Monte-Carlo samples of the convergence study (Supporting Information S12) and their evaluation.

The study draws 10 million distinct configurations (1-16 LEDs, heights 5-15 cm in 1 cm steps) for each of the seeds 42, 1, 2 and 3 with the repository’s utils.monte_carlo_sampler.MonteCarloSampler (uniform LED-count sampling, sequential mode, duplicates removed in the order of the first draw, as in MonteCarloSampler.generate_unique_samples()). With seed 42 the first 5 million configurations are the published sample of the manuscript, row by row (tests/test_seed42_published.py). The first n configurations of a run are exactly the sample that drawing until n distinct configurations would give, so the prefixes of one run serve as the smaller sample sizes.

Every configuration is evaluated for both LED types with analysis.fast_evaluation.FieldBank. The files are written to results/geometric/monte_carlo_convergence/ (about 2.1 GB for four seeds; also available from the Zenodo dataset):

  • mc_seed<seed>_10000000_configs.npz: pos (position indices, int16, padded with -1), z (height in cm), n_leds, seed, n_drawn;

  • mc_seed<seed>_10000000_metrics_<UV|GRN>.npz: mean, std and max of the irradiance in W m-2.

Sampling all four seeds takes about two hours on two cores; a sampler needs about 2 GB of memory at the end of a run. Finished files are not recomputed, so an interrupted run can be restarted.

Usage Example (from the repository root):

python -m analysis.mc_sampling --seeds 42 1 2 3

Convergence of the Monte-Carlo Optimization

Convergence of the Monte-Carlo optimization (Supporting Information S12, Figures S18 and S19).

For every LED type, seed (42, 1, 2, 3) and sample size n (the first 0.5, 1, 2.5, 5 and 10 million distinct configurations of a run of analysis.mc_sampling) the optimization of the manuscript is evaluated with E_bound = 150 W m-2:

  • best_configurations(): the configuration with the highest H E_mean / E_bound, its LED positions and whether it is UV3 / GRN3 (Figure S18c, d and Figure S19);

  • fronts(): the non-dominated configurations of the first 5 million candidates of every seed (Figure S18a, b);

  • front_deviation(): how closely the fronts of the seeds agree. dH(E) is the spread (maximum minus minimum over the seeds) of the homogeneity that each front reaches at the same mean irradiance E, i.e. the highest H of a front point with E_mean >= E. It is evaluated on 4000 equidistant values of E over the range covered by all fronts, only where every front has H >= 0.5. This cut removes the steep end of the 530 nm front, where H drops from 0.5 to below 0 within a few hundredths of a W m-2.
